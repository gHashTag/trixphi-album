# Канон структуры трека (TrixPhi Album)

Единый формат для треков в духе phonk / aggressive male + ethereal female.

## Правила

1. **`[Intro]`** — сразу под заголовком **только** строка в скобках: описание инструментала. **Вокала в интро нет.**
2. **`[Verse 1 — MALE AGGRESSIVE]`** и далее все мужские блоки — весь текст секции **поёт TRI** (роль задаёт заголовок; префиксы в строках не пишутся).
3. **Все припевы** — весь текст секции **поёт PHI**; внутри припева нет мужского вокала.
4. Опционально под заголовком припева — **одна** англ. ремарка в `(скобках)` про звук.
5. Строки текста — **без** префиксов `TRI:` / `PHI:` в начале; пустая строка между секциями.
6. Опционально в конце: **`[Outro — MALE]`** / **`[Outro — FEMALE]`** — короткий спад; иначе финал на последнем припеве.

## Имена секций (в `.md` — дословно, короткий канон)

| № | Заголовок |
|---|-----------|
| 1 | `[Intro]` |
| 2 | `[Verse 1 — MALE AGGRESSIVE]` |
| 3 | `[Chorus — FEMALE ETHEREAL]` |
| 4 | `[Verse 2 — MALE FASTER]` |
| 5 | `[Chorus — FEMALE MYSTERY]` |
| 6 | `[Bridge — MALE TRIPLET FLOW]` |
| 7 | `[Chorus — FEMALE MAXIMUM ENERGY]` |

## Интро: пример содержимого

Минимум — правило в одной строке (для черновика):

```text
(instrumental description only — no vocals)
```

В продакшене строку заменяют на конкретику, правило то же (без вокала), например:

`(Phonk build-up — cowbell + distorted tracking bells)`

## Ремарки под припевами (по желанию, один тип на секцию)

- После **FEMALE ETHEREAL:** `(Reverb-heavy, mysterious, hypnotic tracking melody)`
- После **FEMALE MYSTERY:** `(Ethereal vocals with mysterious layers, more reverb)`
- После **FEMALE MAXIMUM ENERGY:** `(Powerful ethereal vocals, heavy reverb, dark mysterious atmosphere)`

## Вне канона

Треки в другом жанре (например pop-duet с вокалом в интро) **не обязаны** использовать эти семь заголовков; в шапке трека укажи, что применён альтернативный шаблон.

## Короткие имена (устная речь)

Verse 1 → агрессив · Chorus 1 → ethereal · Verse 2 → faster · Chorus 2 → mystery · Bridge → triplet · Chorus 3 → max energy.
